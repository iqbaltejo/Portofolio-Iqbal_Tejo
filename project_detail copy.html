Infrastructure & Automation

Network Modernisation & Zero-Touch Deployment

End-to-end redesign of a legacy on-premises network, migrating 200+ devices to a fully automated, policy-driven infrastructure with 99.97 % uptime SLA.

Date Jan – Jun 2024 Role Network Architect Stack Cisco IOS-XE · Ansible · Python · Zabbix Status Live ✓

01 — Context

The Problem to Solve

Background

The client operated a sprawling campus network built in 2011 — a flat, unmanaged Layer 2 topology with no segmentation, no monitoring, and manual configuration across 14 switches and 6 access-point clusters. VLAN inconsistencies caused broadcast storms twice a month, grinding productivity to a halt and impacting 350+ end users.

Core Challenge

Redesign and migrate the entire infrastructure with zero unplanned downtime during business hours, while building a repeatable, version-controlled automation pipeline so future changes can be deployed in minutes — not hours — by a small IT team with no dedicated network engineers on staff.

02 — Implementation

Technical Approach

Step 01

Discovery & Baseline Audit

Used SNMP polling and CDP/LLDP data collection via Python scripts to auto-generate a full network topology map, exposing undocumented device relationships and rogue switch ports.

Python SNMP CDP/LLDP
Step 02

Hierarchical Design & VLAN Architecture

Designed a three-tier collapsed-core topology with 8 named VLANs, HSRP redundancy, and private VLANs for server isolation — all modelled in GNS3 before physical deployment.

GNS3 Cisco IOS-XE HSRP
Step 03

Ansible Automation & Git Workflow

Wrote 42 idempotent Ansible playbooks for interface configs, VLAN provisioning, and NTP/AAA hardening. All playbooks version-controlled in GitLab with CI linting on every push.

Ansible GitLab CI NAPALM
Step 04

Phased Cut-Over & Rollback Plan

Executed migration in four weekend phases using maintenance windows. Each phase had a tested 15-minute rollback playbook so risk was bounded and stakeholder confidence remained high.

Change Mgmt Runbooks
Step 05

Monitoring & Alerting Stack

Deployed Zabbix with 220 SNMP-based host items and custom trigger thresholds. Grafana dashboards visualise real-time traffic per VLAN; PagerDuty handles on-call escalation.

Zabbix Grafana PagerDuty
Step 06

Documentation & Handover

Delivered a full Confluence wiki: topology diagrams, VLAN register, playbook usage guides, and a "Day 2" runbook for common tasks — enabling junior staff to manage the network independently.

Confluence draw.io
